# Asplenia (standalone)

Same app as the toolkit tab "Asplenia (no spleen)" (hospitalist-toolkit/tools/asplenia/). launch.html → index.html.
Scopes: Patient, Observation, MedicationRequest, Medication, Condition, DiagnosticReport, Procedure, AllergyIntolerance, Encounter (read).
Immunization.read is optional: add it to launch.html and the Code Console registration to read vaccines from Cerner; otherwise paste the CareConnect record.
Made-up patients: index.html?demo=1..7. UNVERIFIED decision support: verify before clinical use.
