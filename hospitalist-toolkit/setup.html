Hospitalist Toolkit – set up your own copy (Cerner sandbox)

Test data only. This runs against the Oracle Health (Cerner) public sandbox with fictional patients. It is a prototype, not approved for clinical use or real patient data.

1. Register the app in your Code Console

  1. Go to code-console.cerner.com and sign in (a free CernerCare account – "Create account" if you do not have one).
  2. Click + New System Account / Application (or New App) and choose:
    • Type: Provider · FHIR version: R4 · Privacy: Public · Intended users: Clinical team
    • SMART Launch URI:
    • Redirect URI:
  3. Product: Millennium (R4). Tick these scopes (all Patient, read): Patient, Observation, MedicationRequest, Medication, Condition, DocumentReference, Binary, AllergyIntolerance. Also tick openid, fhirUser, online_access and launch.
  4. Save, then open the app and copy its Client ID.

2. Paste your Client ID here (saved in this browser only)

3. Launch

  1. In the Code Console, open your app → Begin Testing → pick a test patient → Launch.
  2. Sign in with the sandbox provider account if asked. The toolkit opens with its tabs.

Use the same browser you saved the Client ID in. Other computers or browsers need step 2 again.

4. Open a patient from a link (optional)

The toolkit can also open from a link, for example in a Teams message, without going through PowerChart. In the Code Console, also tick the matching User read scopes (Patient, Encounter, Observation, MedicationRequest, Medication, Condition, DocumentReference, Binary, AllergyIntolerance).
