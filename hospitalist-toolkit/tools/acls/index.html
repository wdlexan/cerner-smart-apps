ACLS: code timer, reversible causes, peri-arrest and after ROSC

Code timer with 2-minute rhythm checks, epinephrine and antiarrhythmic prompts and an event log; Hs & Ts filled from the chart; bradycardia and tachycardia (2025 cardioversion energies); post-ROSC checklist; code status and arrest-risk screen; code note and family update. Read-only.
Decision-support draft. It orders nothing and does not replace ACLS training or the code leader. Written by Claude from the 2025 AHA Guidelines for CPR and ECC (adult ALS, special circumstances, post-cardiac arrest care), as used by Heart & Stroke in Canada, in its own words; not verified. Check doses against the Island Health code cart sheet and pharmacy before real use. The timer runs in this browser only and stores no patient details.
