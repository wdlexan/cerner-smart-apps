## Shared interactive add-on (`interact.js`)
One plain-JavaScript file copied into each app that uses it (now: autoimmune encephalitis, stroke, dementia, hyponatremia and liver; hyponatremia and liver load it through a small `extras.js` so their `app.js` is unchanged). Gives: click a chart match to open the source note with the words highlighted; ✓/✗ on auto-ticks to measure rule accuracy (kept in the browser, CSV export); live countdowns with optional pop-up alerts; trend charts with hover, click and zoom; printable patient/family handouts; values typed once (weight, height) shared by every tab. To add it to another app: copy the file in, load it before the app's script, then call its functions (see the comment at the top of the file).

## iPhone pocket app (no Cerner connection)
`hospitalist-toolkit/index.html?pocket=1` opens the toolkit as a phone app that is **never connected to Cerner** and holds **no patient data**: a blank local-only patient on a non-existent server address (`pocket.js`), so every chart request is answered locally with nothing. Reference sections, calculators, made-up demo patients, typed values and the Consult message button all work; tabs that only read the chart (Today, Patient list, Labs, Critical labs, Notes, AI summary, Forms, Consult summary, ED screen, Hospital at Home, Risk screen, Watch-ahead, Diagnosis check, Choosing Wisely, Mobility) are hidden, and so is Import PDF (`POCKET_HIDE` in `shell.js`). Each tab is squeezed to phone width (`pocketFit`).
- **Install:** on the iPhone open `https://wdlexan.github.io/cerner-smart-apps/hospitalist-toolkit/index.html?pocket=1` in Safari → Share → Add to Home Screen. Open it once with signal so it saves its copy; after that it works offline.
- **Offline:** `pocket-sw.js` (service worker) saves every file listed in `pocket-files.js`; it only acts for pocket pages, so the normal Cerner launch is untouched. Online it always loads the newest version. **After changing any tool, run `node hospitalist-toolkit/pocket-build.js`** so phones pick up the change.
- Icons: `pocket-icons/`, manifest: `pocket.webmanifest`.
